## Question

Which authorized canonical property and date range provide a non-zero live GSC
proof, and what minimum response evidence proves the analytics path works?

## Blocked by

None.

## Resolution

The bounded current window is `2026-06-28` through `2026-07-25` (28 days with
the three-day GSC lag). A temporary, non-production registry scope
`known-answer → sc-domain:hasmed.pl` proved the live analytics path with:

- 428 clicks;
- 28,071 impressions;
- 5,090 rows;
- 10/10 manifest file hashes verified.

The permanent client ownership of `hasmed.pl` is intentionally not inferred by
this probe and remains explicit onboarding work.
